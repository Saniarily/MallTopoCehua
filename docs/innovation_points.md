# 创新点梳理（供论文写作；数值以真实数据第 3 轮结果为准）

## 1. 以拓扑原型为可解释中间态的两阶段策划框架
条件 → **布局类型决策** → 类型内可比原型检索/排序/解释 → 原型保持的可控拓扑扩展 → 几何布局草案。中间态（原型 + 类型 + 证据）是设计师可读、可改的对象，而不是黑箱端到端输出。

## 2. 类型条件化质量模型：把"选型"表述为条件效应问题
- 已有数据分析：评分主要由城市/场地条件解释，布局类型是二阶效应但有因果影响，且**最优类型随城市簇不同**。
- 模型 `E[score | 条件, 类型]`（树模型 + bootstrap CI）直接回答"在这组条件下建哪种类型预期更好"，并同时给出可比案例的经验证据。
- 评估设计：带类型 vs 仅条件的增量解释力、簇内类型排序一致性 τ、最优类型一致率、policy uplift。
- 与保真度协议互补：条件不决定"业主实际选了什么"（type_precision ≈ 随机），但决定"选什么预期更好"——这正是辅助决策的价值所在。

## 3. 质量感知的可比案例检索与无泄漏协议
- grouped split by mall；训练/评估候选均排除同商场楼层；`total_score` 绝不进特征。
- 上下界参照（quality_oracle / random）+ 9 种 ranker 在同一协议下比较；学习型 ranker 达上界 92%。
- 原型保真度协议（label-free，type_hit/precision/metric_dist/quality@K + random/majority/oracle 参照）。

## 4. 小样本深度排序：Transformer+GNN 残差融合
- 经典强基线作主干、深度部分学残差（α 可学习、小初始化）→ 起点即经典模型，不会更差；
- set-Transformer 在候选集合内建模相对关系（listwise），GIN 编码原型图结构；
- 小样本技巧：特征噪声、节点 dropout、snapshot ensembling、早停；成分消融配置齐备。
- 论文叙事：表格 MLP 失败 ≠ 深度无用；给出在 5k 样本级别让深度模型有效的设计原则。

## 5. 自回归 GNN 的原型保持拓扑扩展（与规则/搜索方法同评估器对比）— 真实数据已验证
- 规则/搜索基线满足大纲 5 指标（98%），但 **ground truth 自己只有 94.7%**：大纲指标是合格线而非目标；
- AR-GNN v2：按语料生成顺序 teacher forcing、多合法锚点的集合似然、结构特征 + RWSE；骨架结构性保持；
- 新增**无标签结构一致性指标**（attach recall/precision、degree EMD、new–new 比例）解决"新节点标签不可复现"的评估偏差；
- 真实 600 条留出：attach precision **79.7 vs 43.2**（规则），degree EMD **0.24 vs 0.44**，生长模式与语料一致；best-of-16 同时满足大纲（96.2%）；与 search_expander 搜索预算相同 → 学习型 proposal 的净贡献。

## 6. 工程可复现性
registry/factory + YAML 切换、`_base_` 继承与 `.local.yaml` 机器覆盖、run.json/多 seed 聚合/表格与图自动生成、合成数据 smoke 测试 36 项、真实数据一键脚本；旧仓库只读审计并记录其缺陷（泄漏、oracle 特征、失败的端到端深度模型）。
