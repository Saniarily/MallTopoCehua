# 商场空间智能策划辅助决策系统：实验过程与结果报告

> 面向建筑学背景读者的完整实验记录。所有数字均来自真实数据（1 209 座商场、5 380 个楼层拓扑；5 632 条“骨架→完整拓扑”语料），在作者本机运行得到；每个实验均重复 3–5 次随机种子并报告均值 ± 标准差。图号（F/R）对应 `outputs/thesis/figures/` 中的文件，可用 `python scripts/make_thesis_report.py` 一键重新生成（PNG / PDF / SVG 三种格式，SVG 与 PDF 中文字可在 Illustrator 等软件中直接编辑）。

## 0. 我们在做什么，有什么用

**问题**。商业综合体的前期策划阶段，设计团队面对的输入是一组“外部条件”——项目所在城市的能级与消费力、周边商业竞争强度、地块可建体量——而需要回答的第一个空间问题是：**这个项目适合做成什么样的平面组织方式（布局类型），参考哪些已建成的成功案例，以及如何把参考案例的空间骨架落到自己的场地上**。这一步目前高度依赖策划人员的个人经验和有限的案例记忆。

**思路**。我们把大量已建成商场的“平面拓扑”（把每个店铺、走廊、中庭抽象为节点，把相邻关系抽象为连接）连同其外部条件和公众评价整理成案例库，并构建一个两阶段的辅助决策流程（图 F01）：

- **阶段一 · 选型与找案例**：给定外部条件，先估计每一种布局类型在这组条件下**预期能获得的公众评价**，帮助设计师做类型决策；再在所选类型内检索**条件相近、评价较高**的真实案例，把它们的空间骨架（拓扑原型）连同证据一起呈现。
- **阶段二 · 从骨架到草案**：以所选骨架为起点，按目标规模把它“生长”成完整的平面拓扑（新增店铺单元和走廊连接，骨架本身始终保留），再按场地边界解码为一张平面布局草案（走廊、中庭、临街店铺、主力店）。

**为什么这样做有意义**。(1) 它把“凭经验选型”变成了“有数据支持的选型”，并且每一步都给出可追溯的证据（用了哪些案例、为什么像、评分处于什么水平）；(2) 它输出的不是一张黑箱生成的平面图，而是一个**可读、可改的中间态**（布局类型 + 拓扑骨架），设计师可以在任何一步介入；(3) 生成阶段学习的是真实建成商场的“生长规律”，而不是随意填充。

## 1. 数据基础与实验准则

### 1.0 什么是“平面拓扑”（图 F08）

把一层商场平面中的每个空间单元（店铺、走廊段、中庭、入口）抽象为一个节点，两个单元直接相邻可达就画一条连线，得到的“点—线”图就是该层的**平面拓扑**。它去掉了尺寸和形状，只保留“谁挨着谁、怎么走通”。图 F08 给出六种布局类型各三个真实案例：一字型是一条主轴挂店铺；环型有一个或多个闭合回路；集中型围绕中庭放射；简单型规模小、结构松散。同一类型内部差异不小，这正是需要“检索具体案例”而非“套用类型模板”的原因。

### 1.1 案例库（图 F02、F03）

| 内容 | 规模 |
|---|---|
| 商场 / 楼层 | 1 209 座 / 5 380 层（其中 5 114 层有拓扑图） |
| 外部条件（10 项） | 城市人口、GDP、人均可支配收入、消费总量、区域商场数、最近商场距离、1 km / 2 km 内商场数、项目总建筑面积、Tx 指标；另有城市类别（3 类） |
| 布局类型（6 类） | 一字型、简单环型、多环型、简单型、简单集中型、复杂集中型 |
| 评价 | 商场级公众综合评分（2.9–4.9，中位 4.8） |
| 阶段二语料 | 5 632 条“骨架 → 完整拓扑”配对（骨架平均 27 节点，完整平均 51 节点） |

**数据审计中的两个关键事实**（图 F03）：
1. 评分与**项目体量**的相关性最强（秩相关 +0.48），与城市经济指标的相关性弱（|ρ| < 0.2）；与楼层拓扑指标的相关性中等（|ρ| ≈ 0.2–0.3）。
2. 评分是**商场级**的，同一商场所有楼层评分相同；10 项外部条件中 8 项在同一商场内也完全相同。

第二点直接决定了实验准则（1.2）；第一点提示我们：布局类型对评分的影响是**二阶效应**，需要在控制外部条件之后才能看清——这正是阶段一“类型条件化模型”的设计出发点。

### 1.2 无泄漏的实验准则（图 F04）

- **按商场分组划分**训练 / 验证 / 测试集（967 / 121 / 121 座商场），三者之间商场重叠为零。
- 训练和评估时，候选案例**只取其他商场的楼层**。若允许同商场楼层互为候选，模型会学到“照抄同一商场”而得到虚高的成绩——这是旧方案的主要缺陷之一。
- 综合评分只作为学习目标与评估标准，**绝不作为输入**。所有比较都附带上界（直接按真实评分排序）和下界（随机排序）。
- 阶段二所有生成方法都在**同一批 600 条留出语料**上比较，学习型方法的训练集不含这 600 条。

## 2. 阶段一实验

### 2.0 阶段一在做什么——一个完整示例（图 F05、F09、F10）

图 F09 用一个中等城市的典型条件走完三阶段全流程：(a) 输入十项外部条件；(b) 模型给出六种布局类型的预期评分与置信区间及可比案例数；(c) 在首选类型内检索 Top-3 真实案例的骨架拓扑，设计师选定第 1 名；(d) 阶段二把该骨架扩展为完整走廊关键点网络，旁边放同一楼层**真实建成**的完整网络作对照并标注分支位置正确率；(e) 阶段三：从面积相近的真实楼层轮廓或手绘轮廓中选一个，网络自适应嵌入（外环沿立面内侧、支路垂直、无交叉），一键生成带主次宽度、出入口和中庭的走廊系统——商铺分区留给设计师。图 F10 展示“可比”的含义：把待策划项目与推荐案例的十项条件标准化后并排比较——推荐案例在多数条件上与项目接近，差异大的条件会在解释文本中标注为风险。图 F05 是检索漏斗：5 114 层 → 同类城市同面积档 → 所选类型 → 相似召回 50 → 质量排序 10 → 设计师选定。

### 2.1 实验一：不同排序方法的推荐质量（图 R01、R02）

**目的**。在不知道评分的前提下，仅凭外部条件与案例特征，模型能否把高评分案例排在前面？哪一类方法最合适？

**过程**。以测试集每一个楼层为“待策划项目”，候选 = 同城市类别、同面积档、其他商场的测试楼层。11 种方法在完全相同的数据划分上各跑 3 次随机种子。评价用“前 10 名推荐质量”（NDCG@10：推荐列表前 10 个案例中高评分案例越靠前得分越高，1 为完美）、“两两比较正确率”（任取两个候选，模型判断谁更好的正确率，0.5 为随机）等。

**内容**。经典统计学习方法（岭回归、随机森林、极端随机树、梯度提升、LambdaMART 排序学习）、纯表格深度网络（多层感知机）、本文的 Transformer + 图网络残差融合模型，以及上界 / 下界 / 规则加权三条参照线。

**结果**（表 1；图 R01）。

| 方法 | 前 10 名推荐质量 | 两两比较正确率 |
|---|---|---|
| 评分上界（直接按真实评分排） | 0.751 | 0.963 |
| **极端随机树（本文默认）** | **0.689 ± 0.012** | 0.673 |
| 岭回归 | 0.674 ± 0.004 | 0.693 |
| 梯度提升回归 | 0.677 ± 0.016 | 0.680 |
| Transformer+GNN 残差融合 | 0.672 ± 0.019 | 0.677 |
| LambdaMART | 0.643–0.662 | 0.651–0.679 |
| 随机森林 | 0.627 ± 0.040 | 0.627 |
| 多层感知机（纯表格） | 0.575 ± 0.047 | 0.609 |
| 随机排序（下界） | 0.522 ± 0.003 | 0.481 |

**核心发现**。(1) 在完全不知道评分的情况下，学习型方法达到了上界的 **92%**（0.689 / 0.751），显著高于随机；(2) 几种经典方法之间的差异都在随机种子的波动范围之内——说明外部条件中可利用的信号已经被充分提取，且规律近似线性；(3) 纯表格深度网络明显落后且极不稳定，而加入残差结构的深度模型追平了经典方法（详见 2.3）。

**对建筑策划的意义**。“同城市类别、同体量档次的商场中，哪些更可能获得好评”这一判断，可以在不依赖主观印象的情况下由数据给出，准确度接近“事后已知评分”的九成。这为策划阶段的案例选择提供了一个客观的第一轮筛选。

### 2.2 实验二：哪些信息真正起作用——特征块消融（图 R03）

**目的**。模型依赖的到底是什么信息？拓扑指标、外部条件、还是二者之间的匹配关系？

**过程**。以 LambdaMART 为载体，每次去掉一组输入（重算的图指标 / 旧的 L1-L2 指标 / 18 项扩展拓扑列 / 外部条件 / “条件–案例匹配”特征 / 召回阶段），观察指标变化，3 次随机种子。

**结果**。唯一稳定的信号是**“条件–案例匹配”特征**（即候选案例与待策划项目在各项条件上的差距）：去掉后两两比较正确率从 0.651 降到 0.612、排序相关性从 0.283 降到 0.221；去掉各类拓扑指标反而略有上升，均在噪声范围内。

**核心发现 / 意义**。评分主要由“城市与场地条件”解释，候选案例自身的拓扑指标对**预测评分**几乎没有增量贡献。这与 1.1 的审计一致，也意味着：**不应指望“拓扑指标 → 评分”这条直接路径**，布局类型的作用需要通过条件效应模型（2.4）来刻画。

### 2.3 实验三：深度模型的成分消融（图 R04）

**目的**。旧方案中端到端的 Transformer + 图网络在本数据上失败（样本仅 5 千级）。我们想验证：不是深度模型没用，而是需要针对小样本的结构设计。

**过程**。本文模型 = 以经典模型为主干，深度部分只学习“残差修正”（初始权重很小，起点即等于经典模型），加上四项小样本技巧（输入噪声、节点随机丢弃、多快照集成、早停）。逐一去掉：残差结构、图网络分支、Transformer、小样本技巧。

**结果**。

| 变体 | 前 10 名推荐质量 |
|---|---|
| 完整模型 | 0.668 ± 0.024 |
| 去掉图网络分支 | **0.682 ± 0.005** |
| Transformer 换为普通网络 | 0.676 ± 0.005 |
| 去掉小样本技巧 | 0.650 ± 0.028 |
| **去掉残差结构（端到端）** | **0.645 ± 0.024** |

**核心发现**。(1) **残差结构是关键**：去掉后是唯一超出噪声带的下降，证实“先站在经典模型的肩膀上、深度部分只做修正”是小样本条件下让深度模型有效的设计原则；(2) 去掉图网络分支反而更好且最稳定——与 2.2 一致，候选拓扑结构对预测评分没有增量信息；(3) 相比旧方案的纯深度网络（0.575），本文模型提高了约 0.10，波动减半。

**意义**。论文应如实表述：在阶段一，深度模型的贡献不是“更准”，而是“证明了在建筑案例这类小样本数据上如何让深度模型不失效”，并为阶段二的图网络生成器提供了同一套图编码。

### 2.4 实验四：布局类型的条件效应——给定条件，哪种类型预期更好（图 R05、R06）

**目的**。这是阶段一的核心科学问题：**在给定外部条件下，哪种布局类型预期能获得更高评价？** 已有分析表明类型对评分的影响小于城市/场地条件，但确有因果作用，且最优类型可能随城市类别不同。

**过程**。训练一个“评分 = f(外部条件, 布局类型)”的模型（极端随机树 + 20 次自助重采样得到置信区间）。对测试集每个项目，把 6 种类型逐一代入，得到每种类型的**期望评分与 80% 置信区间**；同时给出同类条件下真实建成该类型的案例数与其实际平均评分作为证据。评估：带类型 vs 仅条件的解释力、每类城市内模型给出的类型排序与实际排序的一致性、模型最优类型与实际最优类型是否一致、“按推荐类型建”与“未按推荐建”的评分差（策略收益）。5 次随机种子。

**结果**。

| 指标 | 值 |
|---|---|
| 加入类型后排序相关性 | 0.573 ± 0.009（仅条件 0.565 ± 0.002） |
| 每类城市内最优类型判断正确率 | **100%**（5 seeds × 3 类城市） |
| 第 1 名与第 2 名置信区间可分的城市类别比例 | 67% |
| 采纳推荐类型的评分收益（全体） | **+0.056 ± 0.026**（评分量程 2.9–4.9） |
| 分城市类别的收益 | 第 1 类 +0.09，第 2 类 **+0.37**，第 3 类 −0.13 |

各类城市的类型期望评分表（图 R05）显示：三类城市中“复杂集中型”均排第一，但**第二名不同**——高能级城市为一字型，中等城市为简单环型，一般城市为多环型；“简单集中型”在中等和一般城市垫底。

**核心发现**。(1) 类型的增量解释力小但方向稳定为正，与“条件是一阶、类型是二阶”的判断一致；(2) 模型在每类城市都正确识别了经验上最优的类型，且采纳推荐在中等城市带来的收益最大（+0.37 分，接近评分量程的五分之一）；(3) 第 3 类城市收益为负、且类型排序与其他两类不同，说明**“最优类型随城市类别变化”是真实存在的**，不能用一个全局结论概括；(4) 排名靠前的“复杂集中型”在各类城市中样本都较少（5–18 个），模型给出的高期望值部分来自小样本的外推，因此系统始终把“可比案例数 n”与推荐一起呈现。

**对建筑策划的意义**。这是系统中最直接面向决策的部分：它把“这块地、这个城市、这个体量，做哪种平面组织方式更有把握”变成了一个带置信区间和证据的量化建议，并且明确告诉设计师在哪些情形下证据不足（区间重叠、样本稀少）。

### 2.5 实验五：推荐案例与真实建成的一致性（图 R07、R08）

**目的**。不看评分，仅凭策划条件推荐的案例，是否“像”该商场最终真实建成的样子？条件本身能否预测业主实际选了哪种类型？

**过程**。对测试集 120 座商场，仅用其外部条件检索前 5 / 前 10 个案例，统计其中与真实建成类型相同的比例、拓扑指标距离、以及推荐案例的实际评分；参照线为随机推荐、永远推荐最常见类型、已知真实类型（上界）。另训练一个“条件 → 类型”的分类器与“永远猜最常见类型”比较。

**结果**。各方法推荐案例中真实类型占比 0.60–0.63，与随机（0.60）相当、低于“永远推最常见类型”（0.77）；但推荐案例的**实际评分**为 4.87–4.89，远高于随机（4.46）和多数类（4.43）。条件 → 类型的预测正确率 31.9%，低于多数类 36.7%。

**核心发现**。外部条件**不决定业主实际选了哪种类型**（实际选型受地块形状、开发商偏好等本数据未记录的因素影响），但**决定检索到的案例是否高质量**。这与 2.4 互为补充：阶段一的定位不是“预测会建成什么”，而是“建议建成什么预期更好，并找出该类型内的高质量可比案例”。

## 3. 阶段二实验

### 3.1 实验设置（图 F06、F07）

**任务**。给定一个骨架（阶段一选出的原型）和目标规模（节点数），生成完整的平面拓扑；骨架的节点与连接必须原样保留。

**数据（第 5 轮，替换前四轮）**。前四轮使用的 `sharegpt_data.json` 经核实为语言模型生成的扩展结果而非真实建成拓扑，其数字全部作废（保留在 `data/results_snapshot/stage2/r4_*` 仅作留痕）。本轮语料直接来自图数据导出：每层 `*_M_simplified.csv` = 骨架（阶段一原型），`*_M.csv` = 真实建成的完整走廊关键点拓扑；6005 层中 5589 层三件齐全且骨架为目标子图（0 例违反），按商场分组、按城市类别分层划分，测试集 575 层。**23% 的真实目标图本身不连通**（导出数据如此），因此“真实建成拓扑”参照行自身也不能 100% 通过大纲判据。

**比较的方法**。
- 规则扩展：按布局类型先验和目标平均连接度，随机做“细分 / 分支 / 加环 / 桥接（新节点闭合环路）”操作，不加骨架—骨架弦、不破坏平面性；
- 规则扩展 + 16 次择优：采样 16 次，按大纲指标挑最好的；
- **自回归图网络（本文，v3）**：一个图神经网络逐个添加新单元，每一步先选一个接点，再反复决定“停止 / 再接一个”（最多 4 个接点，对应真实数据中新节点 1–4 个接点的分布），接点用集合似然（多个合法接点都算对）训练，推理时拒绝破坏平面性的接法（图 F07）。训练顺序 = 语料自身的编号顺序（创建顺序）；
- 本文 + 16 次择优：与规则择优使用**完全相同的采样次数和择优目标**；
- 真实建成拓扑：语料中的答案本身，作为参照行。

**评价指标（两组）**。
- *大纲 5 项合格判据*：阈值按真实建成拓扑的 95% 分位数校准（节点偏差 0、骨架连接保留 ≥70%、路网密度偏差 ≤34%、平均步行路径偏差 ≤17%、耗时 ≤60 s）——真实拓扑比骨架密得多，旧阈值会把真实答案判为不合格。
- *与真实建成拓扑的结构一致性*（本文新增）：**分支位置召回率 / 正确率**（真实拓扑中从骨架各节点长出的分支，生成结果找到了多少、生成的分支有多少位置正确，不依赖新单元编号）、节点连接度分布差异（EMD）、“走廊式生长比例”（新单元之间互相连接的比例）。注意“真实连接命中率”（骨架边 / 目标边）对所有方法恒为 58.3%——骨架原样保留，因此它不再有区分度，不列入比较。

### 3.2 实验六：各生成方法综合比较（图 R09、R10、R14）

**结果**（575 个测试骨架，3 次随机种子，均值 ± 标准差）。

| 方法 | 大纲合格率 | 步行路径偏差 | 分支位置召回 | **分支位置正确率** | 连接度分布差异 ↓ | 走廊式生长比例 |
|---|---|---|---|---|---|---|
| 真实建成拓扑 | 93.2% | 7.1% | 100 | 100 | 0 | 0.23 |
| 规则扩展 | 88.1 ± 3.9% | 7.9% | 41.6 | 34.6 | 0.38 | 0.18 |
| 规则 + 16 次择优 | **97.4 ± 0.2%** | **2.3%** | 43.1 | 40.7 | 0.36 | 0.18 |
| 自回归图网络 | 87.1 ± 1.6% | 11.1% | **66.1** | **71.4** | 0.22 | 0.22 |
| **自回归图网络 + 16 次择优** | 94.3 ± 0.0% | 4.5% | 64.3 | 70.9 | **0.20** | **0.22** |

**核心发现**。
1. **真实建成拓扑在大纲判据下只有 93.2% 合格**（主要因为 23% 的目标图不连通，密度 / 路径偏差按分量计算）。大纲判据衡量“统计上像骨架”，并不衡量“像真实商场”，只能作合格线；方法优劣必须看结构一致性。
2. 在结构一致性上，**本文方法把新分支接到正确骨架位置的正确率是规则方法的 1.75 倍**（70.9% vs 40.7%），召回率 1.5 倍（64.3 vs 43.1），连接度分布差异接近减半（0.20 vs 0.36），“走廊式生长比例”（0.22）与真实建成（0.23）一致，而规则方法偏低（0.18）。
3. 加入 16 次择优后，本文方法大纲合格率从 87.1% 升到 94.3%（超过真实参照行），步行路径偏差从 11.1% 降到 4.5%，结构指标基本不变；与同样 16 次择优的规则方法比，差异仅在候选方案是否“学过真实商场”。规则择优在大纲判据上仍最高（97.4%）——因为择优目标就是大纲指标——但其分支位置正确率只有 40.7%。

**对建筑策划的意义**。规则方法生成的拓扑“数量上对、位置不对”：六成新分支接在真实商场不会接的地方。学习型方法在“哪里长走廊、是否形成回路”上与真实建成的习惯一致，这对后续把拓扑落到平面上至关重要。

### 3.3 实验七：解码策略的权衡（图 R11）

**结果**。贪心解码分支正确率最高（80.2%）但召回只有 47.1%、步行路径偏差 46.8%、合格率跌到 61.9%——它反复选同一批高概率接点，不断延长同一条走廊；带随机性的采样（本文默认）在两者间平衡；采样 + 择优兼顾两端（合格率 94.3%、正确率 70.9%）。

**意义**。“最像真实的局部决策”与“整体路网合理”之间存在张力，择优重排是用大纲目标把整体拉回合理范围的有效手段，也说明大纲指标作为**约束**而非**目标**使用是恰当的。

### 3.4 实验八：自回归图网络的成分消融（图 R12、R13）

**结果**（各自在真实语料上重新训练 10 轮，3 次随机种子评估；括号内为验证集“下一单元第一个接点”预测正确率，随机猜测约 3%）。

| 变体 | 分支位置正确率 | 分支位置召回率 | 连接度分布差异 ↓ | 大纲合格率 | 接点预测正确率 |
|---|---|---|---|---|---|
| **完整模型**（语料顺序 · 多接点集合似然 · 平面性约束） | **71.4** | 66.1 | **0.22** | 87.1% | 41.0% |
| 改用“广度优先”生长顺序 | 69.3 | 68.2 | 0.22 | 87.8% | 30.2% |
| 改用“贪心”生长顺序 | 70.1 | 62.1 | 0.24 | 76.9% | 44.4% |
| 只认单一正确接点 | 54.6 | 80.8 | 0.46 | 54.5% | 31.4% |
| 关闭推理时的平面性约束 | 71.2 | 67.6 | 0.22 | 88.2% | （同一检查点） |

**核心发现**。(1) **多接点集合似然**影响最大：退回“只认单一接点”后，模型倾向于把每个新单元接到很多地方（召回 80.8% 但正确率跌到 54.6%，连接度分布差异翻倍，合格率 54.5%）——真实数据中新单元常有 2–4 个接点（样例层 B000A0E928_1 中 25 个新单元有 19 个是多接点），单标签训练无法表达这一点。(2) **生长顺序**主要影响接点预测正确率（语料顺序 41% vs 广度优先 30%），对最终结构指标的影响较小（±2 个百分点）；贪心顺序验证集正确率更高（44%），但生成时合格率下降到 76.9%——它在训练时看到的是“总是先接最像的”，推理分布更集中。(3) 平面性约束对结构指标几乎无影响（真实语料中模型自发生成的拓扑已基本平面），它是安全阀而非性能来源。

## 4. 总体结论与讨论

1. **阶段一**：在不知道评分的情况下，仅凭外部条件即可把高评价案例排到前列，达到理论上界的九成；布局类型对评分的作用是二阶的，但在控制条件后能被稳定识别，模型在每类城市都找对了经验最优类型，采纳推荐类型的平均收益为 +0.06 分（中等城市 +0.37 分）。
2. **阶段二**：在 5589 层真实建成拓扑上，学习“生长规律”的自回归图网络把新分支接到正确位置的正确率是规则方法的 1.75 倍（70.9% vs 40.7%），连接度分布差异接近减半，走廊式生长比例与真实一致；配合 16 次择优后大纲合格率 94.3%，高于真实参照行（93.2%）。
3. **方法论**：(a) 按商场分组的无泄漏评估和上下界参照，避免了旧方案中的虚高成绩；(b) 在建筑案例这类小样本数据上，深度模型需要以经典模型为主干、只学残差才能不失效；(c) 大纲判据是合格线而非目标——真实建成拓扑自身只有 93.2% 合格——评价生成质量必须引入与真实建成的结构一致性指标；(d) 前四轮基于语言模型生成语料的阶段二结论已全部由真实语料结果替换。
4. **局限与展望**：评分是商场级的公众评价，无法区分楼层；23% 的真实目标图在导出中不连通，拉低了参照行的合格率，后续应按最大连通分量评估或在导出端修复；接点预测的上限受限于真实设计本身的多解性（多数新单元有不止一个接点）。后续可引入楼层级评价、地块形状信息，以及基于结构匹配（而非编号）的更细粒度评价。

## 附录 B · 如何在本机修改图表

- **改文字 / 颜色 / 字号 / 图题**：编辑 `configs/thesis/style.yaml`（`labels` 段是所有中文名，`palette` 段是配色，`figure_titles` 是图题），然后 `python scripts/make_thesis_report.py`。
- **改版式**：每张图对应 `src/mall_space_planner/reporting/figures_*.py` 中一个独立函数（如 `r05_type_tables`），改完 `--only R05` 单独重生成。
- **在 Illustrator / PowerPoint 中改**：直接打开 `.svg` 或 `.pdf`，文字为可编辑文本（未转曲线）。
- **字体**：脚本按 `style.yaml` 中 `cjk_candidates` 顺序自动探测本机字体（Mac 默认 PingFang SC），无需手动配置。
- **数据来源**：`--results` 指向结果目录（默认 `data/results_snapshot`，已内置全部真实结果）；F02/F03 若发现 `data/processed/legacy/cases.csv` 会用真实案例表重算，否则使用审计数字。
